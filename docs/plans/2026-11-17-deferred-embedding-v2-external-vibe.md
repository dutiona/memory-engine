- [LOW] The "no count when `bytes + 2 <= limit`" shortcut sits in the byte-bound paragraph but must also gate llama.cpp's `/tokenize` path: it is safe there too (`count ≤ bytes + 1 EOS ≤ bytes + 2`), and without it every recall query (≤ 1,024 bytes + instruction, `crates/memory-engine-mcp/src/tools/recall.rs:19`) would gain a `/tokenize` round trip inside the 500 ms recall budget, contradicting "short facts cost no extra request".
